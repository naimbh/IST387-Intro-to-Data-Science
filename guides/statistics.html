  1 · Center
  
Mean, median and mode: what is typical?

  
The mean is the average. The median is the middle value after sorting. The mode is the value that shows up most often.

  
The lecture uses these seven numbers: 0, 0, 0, 2, 3, 4, 5.


x <- c(0, 0, 0, 2, 3, 4, 5)

mean(x)      # 2      add them up (14), divide by how many (7)
median(x)    # 2      sorted, the 4th of 7 values is in the middle
mode(x)      # "numeric"   NOT the mode! see the trap below

table(x)                    # counts: 0 appears 3 times, the rest once
names(which.max(table(x)))  # "0"    this is the real mode

  
New in this code
x <- …
<- stores a value in a name, like $x = … in PHP. Read it as “x gets”.
c()
combine: joins values into one vector (R's simple list of same-type values). c(0, 0, 0, 2, 3, 4, 5) is a vector of 7 numbers.
# …
Everything after # on a line is a comment. R ignores it.
mean(x)
Adds the values and divides by how many there are.
median(x)
Sorts the values and returns the middle one.
mode(x)
Despite the name, it returns the data type of x ("numeric", "character"). It does not find the most common value.
table(x)
Counts how many times each value appears, like counting votes. It prints two rows: the values on top and their counts underneath. Same as SQL SELECT x, COUNT(*) … GROUP BY x.
which.max()
Finds the position of the biggest number. On a table it also shows that position's label (the value), so you see two lines: the label on top and the position under it.
names()
Returns just the labels of something, dropping the numbers. Here it keeps the label of the biggest count, which is the mode. Labels are text, so you get "0" in quotes.

  
Read the last line from the inside out: table(x) counts each value (0 appears 3 times, the others once), then which.max() finds the biggest count (the 3, under the label 0), then names() reads off that label, "0".

  
Trap: R has no built-in function for the statistical mode. mode(x) tells you the data type ("numeric", "character"). The lecture shows exactly this surprise. To find the most common value, count with table() and take the biggest with which.max(). The answer comes back as text, "0".

  
With an even number of values, the median is the average of the two middle ones: median(c(1, 2, 3, 10)) is 2.5.


  
Mean
What it's for
Gives one number that stands for the whole group, so you can compare groups quickly (“cars with 4 cylinders average 26.7 mpg, cars with 8 average 15.1”).
How it works
Add every value and divide by how many there are. Think of it as the balance point: if the values were weights on a ruler, the mean is where the ruler balances. That is also why one very heavy weight far out (an outlier) shifts it a lot.
Use it when
The data is roughly symmetric with no extreme values, like heights, test scores or temperatures. It is also the input for the sd, the CLT and regression, so it is the stat you will use most.
Real example
Average daily temperature by month in airquality.

  
Median
What it's for
Gives the value of the “typical” case when a few extreme values would mislead the mean.
How it works
Sort the values and take the one in the middle, so half are below it and half are above. It only cares about order, not size: if the richest person doubles their salary, the median does not move at all.
Use it when
The data is skewed or has outliers: incomes, house prices, populations, waiting times. If the mean and median are far apart, report the median and say the data is skewed.
Real example
State populations: the mean is 4,246 but the median is 2,838, because a few huge states pull the mean up. Most states are closer to 2,838.

  
Mode
What it's for
Tells you the most common value or category, which is the only kind of “average” that works for text and categories.
How it works
Count how often each value appears and pick the biggest count. In R that is table() to count and which.max() to pick. Data can have two modes (bimodal) or none (every value once).
Use it when
The data is categorical (the most common car brand, the most common answer on a survey) or a few repeated numbers (the most common shoe size a store should stock). For continuous numbers like 4.137 and 4.139 the mode is rarely useful, because values seldom repeat exactly.
Real example
table(mtcars$cyl): 8 cylinders is the mode (14 cars). A shop would ask for the mode, not the mean, to know which size to order most.

  
Why have two kinds of average?

  
Six people earn these salaries, in thousands. The last one is the boss.


salary <- c(30, 32, 35, 38, 40, 400)
mean(salary)     # 95.83   pulled up by one person
median(salary)   # 36.5    still looks like a normal salary

  
One extreme value (an outlier) drags the mean toward it. The median barely moves. When data has outliers or a long tail, the median describes "typical" better. That's why news reports use median income.







  2 · Spread (dispersion)
  
Range, variance and standard deviation: how far apart?

  
Two groups can have the same mean and still be very different. The lecture's truck example: you must pick a truck for one container, either a 10-ton or a 7-ton truck.

  

    
GroupContainers (tons)MeanRangesd()

    
      
A2, 5, 5431.73

      
B1, 3, 8473.61

    
  

  
Both means are 4, but group B has an 8-ton container, so a 7-ton truck can't be used for it. The mean alone hides that. Spread tells you how risky "typical" is.


  
Range
What it's for
Shows the full stretch of the data from the lowest to the highest value.
How it works
Max minus min. It uses only two values, so a single outlier changes it completely.
Use it when
You need a quick sense of the limits (“prices run from $5 to $90”) or you are checking for typos, like a person aged 250.

  
The five steps, worked by hand

  
The lecture builds the standard deviation in steps. Here is x <- c(0, 0, 0, 2, 3, 4, 5), whose mean is 2.

  

    
StepWhat you doFor xIn R

    
      
1. RangeBiggest minus smallest5 − 0 = 5range(x) gives 0 5; diff(range(x)) gives 5

      
2. DeviationsEach value minus the mean−2 −2 −2 0 1 2 3x - mean(x)

      
3. Sum of squaresSquare each deviation, add them up4+4+4+0+1+4+9 = 26sum((x - mean(x))^2)

      
4. VarianceThe average squared deviation26 ÷ 6 = 4.33var(x)

      
5. Standard deviationSquare root of the variance√4.33 = 2.08sd(x)

    
  

  
New in this code
range(x)
Returns two numbers: the smallest and the biggest.
diff()
Subtracts each number from the next one. On the two numbers from range(), it gives max − min.
x - mean(x)
Vector math: R subtracts the mean from every value at once, no loop needed. You get 7 deviations.
^2
To the power of 2 (squared). (x - mean(x))^2 squares all 7 deviations at once.
sum()
Adds up all the values.
var(x)
Variance: the sum of squared deviations divided by n − 1.
sd(x)
Standard deviation: the square root of the variance.

  
Why divide by 6, not 7? R's var() and sd() treat your data as a sample and divide by n − 1. The lecture's population formula divides by n, which gives 26 ÷ 7 = 3.71. If an exam question asks what var(x) prints, use n − 1.

  
    
    
  • Why square? The plain deviations always add up to 0 (−6 + 6), so you can't average them. Squaring makes every distance positive.
    • 
    
  • Why use sd instead of variance? Variance is in squared units ("14 squared inches"), which nobody can picture. The sd is back in the original units ("3.7 inches"). The lecture asks which works better, and the answer is the sd.
    • 
    
  • If every value is the same, nothing is spread out: sd(c(5, 5, 5)) is 0.
    • 
  

  
Variance and standard deviation
What it's for
Measure how far the values typically sit from the mean, so you know how much to trust “typical”. A small sd means most values are close to the mean; a large sd means they are scattered.
How it works
Find each value's distance from the mean, square the distances so negatives don't cancel positives, average them (that's the variance), then take the square root to get back to the original units (that's the sd). Every value counts, so outliers raise the sd a lot.
Use it when
You want to compare consistency (two machines both fill 500 g bags on average, but which one is steadier?) or judge whether a value is unusual. For a bell-shaped variable, about two-thirds of values sit within 1 sd of the mean and about 95% within 2 sd.
Real example
Truck groups A and B both have a mean of 4 tons. The sd (1.73 vs 3.61) shows that B is riskier, because its values are spread out.







  3 · Quantiles
  
Quantiles, IQR and summary()

  
A quantile is a cut point. The 25% quantile (Q1) is the value that a quarter of the data falls below. The median is the 50% quantile.

  
Quantiles and the IQR
What it's for
Tell you where a value stands compared with the rest (“you scored higher than 90% of the class”) and describe spread without being fooled by outliers.
How it works
Sort the data and find the value at a given position: 25% of the way along is Q1, 75% is Q3. The IQR is Q3 − Q1, the width of the middle half, so the extreme top and bottom quarters are ignored.
Use it when
The data is skewed (use the IQR with the median, the same way you use the sd with the mean), you need cut-offs (“the top 5%”), or, in Week 4, you need the middle 95% of a sampling distribution.
Real example
Doctors' growth charts: a child at the 90th percentile for height is taller than 90% of children the same age.


quantile(x)
#   0%  25%  50%  75% 100%
#  0.0  0.0  2.0  3.5  5.0

IQR(x)                      # 3.5    Q3 − Q1: the spread of the middle half
quantile(mtcars$mpg, c(0.05, 0.95))
#   5%  95%
# 12.0 31.3   90% of the cars fall between these two values

summary(x)
#  Min. 1st Qu.  Median    Mean 3rd Qu.    Max.
#   0.0     0.0     2.0     2.0     3.5     5.0

  
New in this code
quantile(x)
Returns the cut points at 0%, 25%, 50%, 75% and 100% of the sorted data. Give it a second argument to pick your own cut points.
IQR(x)
Interquartile range: the 75% cut point minus the 25% cut point.
mtcars
A data frame (a table) built into R: 32 cars with 11 columns such as mpg and weight.
mtcars$mpg
$ picks one column from a data frame, like $car->mpg in PHP. The result is a vector.
c(0.05, 0.95)
The cut points you ask for, written as decimals: 0.05 is 5%.
summary(x)
Prints six numbers at once: min, Q1, median, mean, Q3 and max.

  
    
    
  • summary() is the quickest look at a numeric column: the five-number summary plus the mean. It's the same six numbers you see when you run summary(df) on a data frame.
    • 
    
  • The IQR resists outliers like the median does, because it ignores the top and bottom quarters.
    • 
    
  • The printVecInfo function from the homework prints the 0.05 and 0.95 quantiles this way.
    • 
  







  4 · Shape
  
Histograms, box plots and skew

  
The lecture uses state populations, which are built into R as state.x77 (in thousands, from 1975). The numbers match the lecture exactly.


pop <- state.x77[, "Population"]
mean(pop)      # 4246.42
median(pop)    # 2838.5
sd(pop)        # 4464.491
hist(pop)                # 5 wide bars: 38 states land in the first one
hist(pop, breaks = 20)   # more, thinner bars show more detail

  
New in this code
state.x77
A table of facts about the 50 US states that comes with R. It is a matrix (a grid of numbers), not a data frame, and population is in thousands.
[, "Population"]
Square brackets pick parts of a table: [rows, columns]. Leaving the rows blank means “all rows”, so this takes the whole Population column.
hist()
Draws a histogram: it splits the numbers into bins and draws one bar per bin, as tall as the count.
breaks = 20
An option (named argument) that asks for about 20 bins instead of R's default.

  

  
hist(pop, breaks = 20). Each bar is 1,000 thousand people wide. Most states are small, and a few huge ones make a long tail to the right.

  
Histogram
What it's for
Shows the shape of one numeric variable at a glance: where values bunch up, how wide they spread, whether there is a long tail, and whether there are two peaks.
How it works
Cut the number line into equal bins and draw one bar per bin, as tall as the count of values inside it. More bins (breaks = 20) show more detail; too many make it jagged.
Use it when
Before choosing any other statistic. The shape tells you whether the mean or the median is the honest “typical” value.

  
A histogram counts how many values land in each bin. A long tail to the right is called right skew (positive skew). The tail pulls the mean to the right of the median, here 4,246 against 2,838.

The box plot shows the same data in five numbers


boxplot(pop, horizontal = TRUE)

  
New in this code
boxplot()
Draws a box plot. horizontal = TRUE lays it on its side; the default is upright.

  
Box plot
What it's for
Summarizes a variable in five numbers and flags outliers. It's best for comparing several groups side by side, like mpg for 4, 6 and 8 cylinders.
How it works
The box runs from Q1 to Q3 with a line at the median. Whiskers reach to the furthest values within 1.5 × IQR of the box. Anything further is drawn as a dot and treated as an outlier.
Use it when
You compare groups, or you want to spot outliers quickly. A histogram shows the shape in more detail; a box plot is more compact.

  

  
The box is the middle half of the states (Q1 to Q3), and the line inside is the median. Whiskers reach out to 1.5 × IQR. Points beyond them are outliers: Illinois, Pennsylvania, Texas, New York and California.


  
Comparing with a normal curve

  
The lecture makes 500 random numbers from a normal (bell) distribution with the same mean and sd as the states. It's a function inside a function:


hist(rnorm(500, mean(pop), sd(pop)))   # bell-shaped, unlike the real data

  
New in this code
rnorm(n, mean, sd)
Random normal: makes n random numbers from a bell curve with the mean and sd you give. Here it makes 500, with the same mean and sd as the states.
f(g(x))
A function inside a function. R runs the inside first: rnorm() makes the numbers, then hist() draws them.

  
The real data doesn't look like that, which tells you the state populations are not normally distributed.







  5 · Categories
  
Counting categories with table()

  
You can't take the mean of text or categories. For those, you count. This is a frequency distribution.

  
Frequency tables and proportions
What it's for
Describe categorical data: how many of each kind, and what share of the whole.
How it works
table() counts each distinct value. prop.table() divides each count by the total so the shares add up to 1, which makes groups of different sizes comparable.
Use it when
The column is a category (species, state, yes/no) or a number with only a few distinct values (cylinders, gears). Proportions are better than counts when you compare two datasets of different sizes.


table(mtcars$cyl)
#  4  6  8
# 11  7 14     14 cars have 8 cylinders

prop.table(table(mtcars$cyl))
#     4     6     8
# 0.344 0.219 0.438    shares that add up to 1

length(unique(df$Location))   # how many different values (HW 3)
summary(iris$Species)         # summary() of a factor also gives counts: 50 50 50

  
New in this code
prop.table()
Turns counts into shares of the total: each count divided by the sum, so they add up to 1.
unique()
Removes repeats and keeps one copy of each value, like SQL SELECT DISTINCT.
length()
How many values a vector has. length(unique(x)) is SQL's COUNT(DISTINCT x).
iris
A built-in data frame of 150 flowers from three species.
factor
R's type for categories with a fixed set of levels, like an ENUM column. Species is a factor, so summary() counts each level instead of averaging.

  
SQL brain: table(df$x) is SELECT x, COUNT(*) … GROUP BY x.







  6 · By group
  
The same stat for each group

  
The mean mpg for each number of cylinders, done three ways. All three give the same numbers.

  
Stats by group
What it's for
Turn one big average into a comparison between groups, which is where most real insights come from (“8-cylinder cars use far more fuel”).
How it works
Split the rows by the group column, apply the statistic to each piece, and put the answers back together. This is exactly SQL's GROUP BY.
Use it when
You suspect a category matters: month vs temperature, species vs petal size, cylinders vs mpg.


tapply(mtcars$mpg, mtcars$cyl, mean)                 # base R
aggregate(mpg ~ cyl, data = mtcars, mean)            # base R, returns a data frame
mtcars %>% group_by(cyl) %>% summarize(m = mean(mpg))  # dplyr: needs library(tidyverse)
#     4     6     8
# 26.66 19.74 15.10

  
New in this code
tapply(values, groups, f)
Splits the values by group and applies the function to each group. Here: mpg split by cyl, then mean on each part.
aggregate(y ~ g, data, f)
Does the same, but takes a formula and returns a data frame. Read mpg ~ cyl as “mpg by cyl”.
%>%
The pipe: passes the result on the left into the function on the right. Read it as “then”, like chaining methods in Laravel.
group_by()
From dplyr: marks the groups, like SQL GROUP BY. It doesn't change the numbers yet.
summarize()
From dplyr: calculates one row per group. m = mean(mpg) names the new column m.
library(tidyverse)
Loads the tidyverse packages, which include dplyr. Without it R says “could not find function”.

  
Swap mean for median, sd or max to get any other statistic per group.







  7 · Two columns
  
Correlation: do two columns move together?


cor(mtcars$wt, mtcars$mpg)   # -0.868

  
New in this code
cor(x, y)
Correlation between two numeric columns of the same length. wt is weight in 1,000 lb.

  
Correlation
What it's for
Measures in one number how strongly two numeric columns move together in a straight line.
How it works
It checks, row by row, whether a value above its mean in one column tends to go with a value above (or below) its mean in the other. The result is scaled to run from −1 to +1, so it has no units and you can compare it across datasets.
Use it when
You are exploring which variables are related before building a regression. It only catches straight-line patterns, and it can be fooled by a single outlier.

  
Correlation runs from −1 to +1. Near +1 means both go up together. Near −1 means one goes up as the other goes down. Near 0 means no straight-line link. Here, heavier cars get fewer miles per gallon, strongly.

  
Correlation is not causation. It describes the data; it doesn't prove that one thing causes the other.







  8 · Missing values
  
The NA trap


mean(c(1, NA, 3))                 # NA     one missing value spoils the result
mean(c(1, NA, 3), na.rm = TRUE)   # 2      na.rm = "NA remove"
sum(is.na(airquality$Ozone))      # 37     count the missing values first

  
New in this code
NA
“Not Available”: R's marker for a missing value, like SQL NULL.
na.rm = TRUE
An option meaning “NA remove”: skip the missing values before calculating.
is.na()
Checks each value and returns TRUE where it is missing and FALSE where it isn't.
sum(TRUE/FALSE)
R counts TRUE as 1 and FALSE as 0, so sum(is.na(x)) counts the missing values.
airquality
A built-in data frame of daily air readings in New York in 1973. Ozone has 37 gaps.

  
na.rm = TRUE works the same way in median, sd, var, min, max, sum, range and quantile.

  
Why does R return NA instead of just skipping it? On purpose: R refuses to guess. If a value is unknown, the true mean is unknown too, so R makes you decide out loud with na.rm = TRUE. Always count the missing values first. If a large share is missing, the mean of what is left may not represent the whole group.






  Part B · Weeks 4–5
  
Sampling, randomness and inference

  
Descriptive stats describe the data you have. Inferential stats use a sample to say something about a bigger population you can't see all of.






  9 · Population and sample
  
Why we sample

  
The population is everything you want to study, like every iPhone in use or every US voter. You almost never get all of it. A sample is the part you actually collect.

  
    
    
  • Random sampling: every element has an equal chance of being picked.
    • 
    
  • With replacement: you put each item back before the next draw, so it can be picked again. That is replace = TRUE.
    • 
    
  • Randomness means one draw is uncertain. Only the long run (many draws) becomes predictable.
    • 
  

  
Random sampling
What it's for
Lets you learn about a huge population from a small, affordable piece of it. Polls ask about 1,000 people to describe 200 million voters.
How it works
Every member has the same chance of being picked, so no group is favored on purpose or by accident. Then, on average, the sample looks like the population, and the errors are random rather than one-sided.
Use it when
Always, when you can't measure everyone. A non-random sample (only asking your friends, only online users) gives biased results that more data can't fix.
Real example
Asking only students in the library about study hours would overstate how much students study. Picking random student IDs would not.


pop <- state.x77[, "Population"]       # the "population": all 50 states
sample(pop, size = 6, replace = TRUE)   # 6 random states; different every time
mean(sample(pop, size = 6, replace = TRUE))   # the mean of one sample

set.seed(10)    # fixes the random numbers so you get the same ones every run

  
New in this code
sample(x, size, replace)
Picks size random values from x. replace = TRUE puts each one back after picking, so the same value can come up twice.
set.seed()
Sets the starting point of R's random number generator, so the “random” results come out the same every time you run the code.

  
Why set.seed()? It makes random results repeatable, so your knitted homework and your classmate's run show the same numbers. The seed value itself (10, 110, 387) doesn't matter.






  10 · Coin flips and the LLN
  
Random coin flips and the Law of Large Numbers

  
Things with two outcomes (heads or tails, red or blue, survived or not) follow the binomial distribution. rbinom() makes random ones.


rbinom(n = 8, size = 1, prob = 0.5)   # 8 flips of 1 fair coin: e.g. 1 0 0 1 0 0 0 0
#        n = how many results   size = coins per result   prob = chance of a 1

flips <- factor(rbinom(8, 1, 0.5), labels = c("red", "blue"))   # name the 0s and 1s
table(flips)      # count each color
barplot(table(flips))

  
New in this code
rbinom(n, size, prob)
Random binomial: random results for things with two outcomes. Each result counts the 1s (successes) in size tries, each with chance prob. With size = 1, each result is a single 0 or 1, like one coin flip.
factor(…, labels = )
Turns the 0s and 1s into categories with readable names: 0 becomes "red" and 1 becomes "blue".
barplot()
Draws one bar per category, as tall as its count. Use it for counts from table(); use hist() for raw numbers.

  
With only 8 draws, a 6–2 split is normal. Here is the share of heads as the number of flips grows (with set.seed(1)):

  

    
FlipsR codeShare of heads

100,000mean(rbinom(100000, 1, 0.5))0.50009

    
  

  
Law of Large Numbers (LLN): the more observations you collect, the closer your result gets to the true value. It is about accuracy.

  
Why the LLN matters
What it's for
It's the reason bigger samples are more trustworthy, and why casinos, insurance companies and polls can make reliable predictions from random events.
How it works
Random luck goes both ways. In 10 flips, a lucky streak of heads is a big part of the total. In 100,000 flips, the lucky streaks up and down cancel out, so the share settles at the true 50%.
Use it when
You decide how much data to collect, or you explain why a small sample gave a strange result. Small samples swing; large samples settle.
Real example
A new restaurant with three 5-star reviews isn't proven great. One with 2,000 reviews averaging 4.6 is much more reliable.

  
The mean of 0s and 1s is the share of 1s, which is why mean() works here.






  11 · Sampling distributions and the CLT
  
Many samples: the sampling distribution

  
One sample mean is a bit off by chance. To see how far off, repeat the sampling many times with replicate() and look at all the means together. That pile of means is the sampling distribution.


replicate(4, mean(sample(pop, size = 16, replace = TRUE)))
# 3859.250 3701.875 2854.375 3272.375   four sample means

sampleMeans <- replicate(2000, mean(sample(pop, size = 16, replace = TRUE)))
mean(sampleMeans)     # about 4,240: very close to the true 4,246
hist(sampleMeans)

  
New in this code
replicate(k, expr)
Runs the same code k times and keeps every result in a vector. Here it repeats “draw 16 states, take their mean” 2,000 times, giving 2,000 sample means.

  
The lecture shows the mean of the means getting closer to 4,246 as you replicate more: 4 samples were off by 3.5%, 400 by 2%, and 2,000 by only 0.09%. That is the LLN again.

  

  
2,000 sample means for each sample size (set.seed(4)). The populations themselves are right-skewed (see the histogram in Part A), but the sample means form a bell. Bigger samples give a narrower bell.

  
Central Limit Theorem (CLT): take many random samples and compute each one's mean. As the sample size grows, the means form a normal (bell-shaped) distribution, even when the population itself is not normal. It is about shape.

  
Sampling distributions and the CLT
What it's for
Tell you how much a sample mean would change if you sampled again, which is how you judge whether a result is real or just luck. The CLT is why bell-curve methods work for almost any data.
How it works
Each sample mean averages out some of the extreme values, so means cluster near the true mean more tightly than single values do. Highs and lows in a sample tend to cancel, so means far from the center are rare. That gives the bell shape. Bigger samples cancel more, so the bell gets narrower.
Use it when
You want to compare one sample's mean with what chance alone would produce, as in the mystery sample.

  12 · Quantiles and the mystery sample
  
Is this sample from our population?

  
A quantile is a percentile written as a decimal: the median is the 0.50 quantile. quantile(0:200, c(0.25, 0.75)) gives 50 and 150.

  
The lecture gives a mystery sample of 16 numbers and asks whether it came from the states.


MysterySample <- c(333, 1088, 3699, 3805, 3135, 3390, 99, 1049,
                   235, 129, 4299, 3649, 2295, 4663, 1837, 2711)
mean(MysterySample)                          # 2276
quantile(sampleMeans, probs = c(0.025, 0.975))
#   2.5%  97.5%
#   2332   6656     the middle 95% of sample means
mean(sampleMeans < 2276)                     # 0.0215: only about 2% are this low

  
New in this code
probs = c(0.025, 0.975)
Asks quantile() for the 2.5% and 97.5% cut points, which mark off the middle 95%.
sampleMeans < 2276
Compares every sample mean with 2276 and returns TRUE or FALSE for each one.
mean(TRUE/FALSE)
TRUE counts as 1 and FALSE as 0, so the mean is the share that is TRUE: here 0.0215, or 2.15%.

  

  
The shaded band is the middle 95% of 2,000 means of real state samples. The mystery mean falls outside it, in the left tail. Your exact cutoffs vary a little with the seed; the lecture got 2,391 and 6,591.

  
If the mystery sample really came from the states, a mean this low would happen only about 2% of the time. That's rare, so we infer it probably came from somewhere else. This is the core idea of inferential statistics.

  
Why the 2.5% and 97.5% cut-offs?
What it's for
They draw a line between “ordinary chance” and “too unusual to be chance”.
How it works
Build the sampling distribution, keep its middle 95%, and treat anything outside as unusual. Outside means it would happen less than 5% of the time (2.5% in each tail) if the sample really came from that population. The 5% is a convention, the same one behind “p < 0.05” in Part C.
Use it when
You test a claim: does this batch, sample or group really belong to the known population? It's the same logic as a p-value, just done by simulation instead of a formula.

  13 · Linear regression words
  
The regression equation

  

    
TermPlain wordsOil example

    
      
Dependent (outcome) variable, YWhat you want to predictrepairs

      
Independent (predictor) variables, XWhat you predict it withoilChanges, miles

      
InterceptThe predicted Y when every X is 035.7

      
Coefficient (slope, weight)How much Y changes when that X goes up by 1, with the others held fixed−57.3 per oil change

      
Y-hat (Ŷ)The predicted YPredicted repair cost

    
  

  
The equation is Y = a + bX. With two predictors: repairs = 35.7 − 57.3 × oilChanges + 0.0051 × miles.

  
In R, ~ means "is predicted by": lm(repairs ~ oilChanges + miles, data = oil). Read lm(y ~ ., data = df) as "predict y from every other column".

  
Linear regression
What it's for
Does two jobs: it predicts a number for new cases (the repair cost of a car), and it explains how much each predictor matters, with the others held fixed.
How it works
R finds the straight line (or flat surface, with two predictors) that makes the squared misses, the residuals, as small as possible. That's why it's called “least squares”. The slope of that line is the coefficient.
Use it when
The outcome is a number (cost, price, score) and you expect roughly straight-line relationships. For a category outcome (survived yes/no), use a tree or an SVM instead.
Real example
A fleet manager can see that each oil change is linked to about $57 less in repairs and decide how often to change the oil.

What a p-value really is
What it's for
Answers the question “could this pattern be pure luck?” for each predictor.
How it works
R assumes the predictor has no real effect (a coefficient of 0) and asks how likely it would be to see an estimate this far from 0 just by chance. A tiny p-value means “very unlikely by luck”, so we call the effect significant. It's the same idea as the mystery sample landing outside the middle 95%.
Use it when
You decide which predictors to keep or trust. A p-value says whether an effect is likely real; the estimate says how big it is. A significant effect can still be too small to matter.

  
R-squared
What it's for
Tells you how well the model explains the outcome overall, on a 0 to 1 scale.
How it works
Compare the model's misses with the misses of a lazy model that always predicts the mean. If the model cuts the squared misses by 86%, R² is 0.86. Adjusted R² takes a small penalty for each extra predictor, because adding any column, even a useless one, never lowers plain R².
Use it when
You compare models of the same outcome (oil only: 0.74; oil and miles: 0.86) or describe how complete the model is. A low R² doesn't mean the model is wrong, only that other factors matter too.

  
Reading p-values: e-05 means "move the decimal point 5 places left". Any p-value below 0.05 is called significant. A p-value tells you whether a predictor matters; the estimate tells you how much and in which direction.

Plugs new rows into the model's equation and returns the predicted Y. newdata must be a data frame whose column names match the predictors.

The model doesn't prove that oil changes cause lower repairs, and it can predict nonsense far outside the data, such as negative repair costs for 10 or more oil changes in the one-predictor model. Regression shows association, not causation.

The confusion matrix
What it's for
Shows not just how often the model is right, but what kind of mistakes it makes.
How it works
Rows are what the model predicted and columns are what really happened. The diagonal is correct; the other two cells are the two kinds of error. On the Titanic, the model missed 441 survivors but raised only 20 false alarms.
Use it when
Mistakes have different costs. Missing a sick patient is worse than a false alarm, so you check which cell the errors fall in, not just the overall accuracy.

  
Why compare with the NIR?
What it's for
Stops you from being impressed by an accuracy that any lazy guess could reach.
How it works
If 70% of customers are “Good”, a model that says “Good” every time is already 70% accurate while learning nothing. Real skill is only the part above that. The P-Value [Acc > NIR] checks whether the gap is bigger than luck.
Use it when
Always, for classification. The more lopsided the classes (99% not fraud), the more misleading accuracy alone becomes.






  16 · Training, testing and overfitting
  
Why we test on new data

  
    
    
  • Training set: the rows the model learns from. Test set: rows it has never seen, used to measure accuracy honestly. createDataPartition(y, p = 0.80, list = FALSE) picks 80% for training and keeps the class shares the same in both sets.
    • 
    
  • Overfitting: the model learns the noise in the training data, so it scores well on training data and badly on new data. Underfitting: the model is too simple to catch the pattern.
    • 
    
  • Training error is measured on the data the model learned from, so it is too optimistic. Cross-validation error (cross = 3 in ksvm) holds back part of the training data in turns and is a fairer estimate.
    • 
  

  
Why a separate test set?
What it's for
Gives an honest grade. A model graded on the questions it studied always looks better than it really is.
How it works
Hide some rows before training, train on the rest, then predict the hidden rows and compare with the real answers. Cross-validation repeats this inside the training data: with cross = 3 it trains on two-thirds, tests on the last third, rotates three times and averages the errors.
Use it when
Every time you report how good a classification or prediction model is. Training accuracy alone can't detect overfitting.
Real example
A student who memorizes last year's exam answers scores 100% on that paper and fails a new one. That student is an overfitted model.

  Quiz
  
Sixteen questions, exam style

  
Answer on paper first, then open each answer.

  

    
1. What does median(c(9, 1, 5, 3)) return?

      
Show answer
4. Sorted it is 1 3 5 9, an even count, so R averages the two middle values: (3 + 5) ÷ 2.

    
2. A student runs mode(scores) to find the most common score and gets "numeric". Why, and what should they run?

      
Show answer
mode() returns the data type. Use names(which.max(table(scores))).

    
3. House prices in a town have a mean of $450k and a median of $310k. What shape is the distribution, and which number better describes a typical house?

      
Show answer
Right skewed: a few very expensive houses pull the mean up. The median describes a typical house better.

    
4. Two classes both average 75. Class A has sd 3 and class B has sd 15. What does that tell you?

      
Show answer
Class A's scores sit close to 75. Class B's are spread out, with some much higher and some much lower.

    
5. What does sd(c(7, 7, 7, 7)) return?

      
Show answer
0. No value is any distance from the mean.

    
6. Why do we usually report the standard deviation instead of the variance?

      
Show answer
The sd is in the same units as the data (inches, tons). The variance is in squared units, which are hard to picture.

    
7. What does this return?
mean(c(10, NA, 20))

      
Show answer
NA. Add na.rm = TRUE to get 15.

    
8. Write one line of base R that gives the mean Temp for each Month in airquality.

August (84.0) is just warmer than July (83.9).

    
9. You flip a fair coin 10 times and get 7 heads. Then you flip it 100,000 times and get 50.01% heads. Which idea explains this?

      
Show answer
The Law of Large Numbers: with more observations, the result moves toward the true value of 0.5.

    
10. Population incomes are strongly right-skewed. You take 2,000 samples of size 50 and draw a histogram of their means. What shape do you expect, and which idea says so?

      
Show answer
A bell (normal) shape, by the Central Limit Theorem, even though the incomes themselves are skewed.

    
11. What does this code do, in words?
replicate(500, mean(sample(pop, size = 10, replace = TRUE)))

      
Show answer
It draws 10 values from pop with replacement, takes their mean, and repeats that 500 times. You get 500 sample means: a sampling distribution.

    
12. The middle 95% of your sample means runs from 2,332 to 6,656. A new sample has a mean of 5,100. Is it unusual?

      
Show answer
No. 5,100 is inside the middle 95%, so a sample like it could easily come from the same population.

Each extra unit of size adds about 150 to the predicted price, and p = 0.002 < 0.05, so size is a significant predictor.

Show answer
The model explains only about 25% of the variation in the outcome. The other 75% comes from things the model doesn't include.
